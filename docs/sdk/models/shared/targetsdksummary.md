# TargetSDKSummary

Lean representation of a target with only the fields needed by the dashboard UI. Excludes large fields like workflow YAML files to reduce response payload size.

## Example Usage

```typescript
import { TargetSDKSummary } from "@speakeasy-api/speakeasy-client-sdk-typescript/sdk/models/shared";

let value: TargetSDKSummary = {
  generateGenLockId: "<id>",
  generateTarget: "<value>",
  id: "<id>",
  lastEventCreatedAt: new Date("2026-10-24T01:51:35.802Z"),
};
```
